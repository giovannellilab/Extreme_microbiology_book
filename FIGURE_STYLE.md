# FIGURE_STYLE.md

## Purpose

Figures in *Microbiology of Extreme Environments* should form one coherent visual family.

House style:

**Natural History Museum Minimal**

The target is:

- scientifically precise
- visually clear
- restrained
- warm but technical
- contemporary
- readable in print and on screen

The visual style serves the science. It must never dominate it.

# 1. Core visual language

Use:

- pure white background
- generous negative space
- clear hierarchy
- restrained detail
- fine, precise linework
- muted natural colours
- limited accent colours
- direct labelling
- clean annotations

Avoid:

- generic infographic aesthetics
- glossy biotech/startup graphics
- decorative biology
- excessive boxes and arrows
- cartoon styling
- cinematic or science-fiction rendering
- ornate historical plate styling
- cold engineering-drawing aesthetics
- unnecessary texture, shadows or 3D effects

Figures should feel like modern scientific natural-history illustrations rather than software infographics.

# 2. Scientific purpose first

Every figure must answer a clear scientific or pedagogical question.

Start from the scientific object being shown:

- cell
- molecule
- environment
- gradient
- dataset
- comparison
- process

Do not start from a layout of boxes and arrows unless the concept is inherently sequential.

Major figures should visualise major concepts, not document the evidence-audit process.

Do not add microorganisms, cells or structures merely for decoration.

# 3. Typography

Use sans serif throughout figures.

Figure titles should normally appear inside the figure, usually at the top-left.

A short subtitle may be used when useful.

At final publication size:

- preferred labels: 9–11 pt
- secondary labels: 8.5–9 pt
- panel letters: 12–14 pt
- short headings: 11–14 pt
- nothing below 8.5 pt

Assume a maximum final figure width of approximately 180 mm.

If labels need to be smaller than 8.5 pt, simplify the figure instead.

Scientific names follow the book's italicisation rules.

# 4. Colour

Use a restrained palette.

Suitable colours include:

- muted blues
- teal
- desaturated greens
- ochre
- warm orange
- rust
- muted red
- purple where useful
- neutral greys

Colour must communicate meaning.

Use it to show:

- states
- compartments
- gradients
- environmental zones
- related elements
- focal mechanisms

Do not use colour only for decoration.

Figures must remain interpretable without relying on colour alone.

# 5. Illustration style

Prefer crisp scientific illustration with:

- clear edges
- restrained tonal modelling
- sparse texture
- slightly organic but controlled linework

Avoid:

- painterly rendering
- airbrushed surfaces
- glossy 3D appearance
- exaggerated outlines
- unnecessary microscopic detail

Simplification is encouraged when it improves understanding, provided the scientific feature being taught remains correct.

State when a figure is schematic or not to scale if misunderstanding is possible.

# 6. Figure types

## Mechanism and cellular figures

Show one main scientific question.

Use only the structures needed to explain the mechanism.

Where useful, organise around:

environmental condition
→ cellular consequence
→ biological problem
→ adaptation
→ functional outcome

Avoid molecular inventories.

## Environmental figures

Show the physical setting together with the relevant:

- gradients
- chemistry
- energy sources
- microbial niches or processes

Environmental scenes may be more illustrative, but they must remain scientifically controlled.

Use real photographs where seeing the actual environment materially improves understanding.

## Comparative figures

Compare the same conceptual dimensions across panels or objects.

Use symmetry where it improves comparison.

Avoid irrelevant anatomical detail.

## Quantitative and abstract figures

Use:

- precise axes
- explicit units
- minimal decoration
- clear annotations
- restrained colour

Do not force illustrative texture into quantitative plots.

Do not add decorative organisms to graphs or abstract diagrams.

# 7. Photographs

Photographs should remain visually authentic.

Prefer:

1. original author photographs
2. appropriately licensed scientific photographs
3. external photographs only when they add clear scientific value

Do not stylise photographs to resemble drawings.

Annotations should use the same typography and restrained visual language as diagrams.

Use scale bars where appropriate.

# 8. Redrawing scientific concepts

Scientific concepts may be redrawn in the book's visual language.

Do not trace or cosmetically modify copyrighted figures.

Instead:

- identify the scientific concept
- verify it from appropriate sources
- design a new composition
- use the book's own hierarchy and explanatory logic

The scientific concept may be established; the artwork must be original.

# 9. Labels and panels

Prefer direct labels over large legends.

Keep labels concise and close to what they describe.

Avoid crossing leader lines and long paragraphs inside figures.

Multi-panel figures should answer one coherent question.

Use:

A, B, C, D...

for panel labels.

Do not combine unrelated content into a multi-panel figure merely to save space.

# 10. Scale and quantitative meaning

Use scale bars when physical scale matters.

Do not imply quantitative precision when a relationship is only conceptual.

Clearly distinguish where relevant between:

- measured values
- representative ranges
- conceptual gradients
- schematic relationships

# 11. Captions

Captions should explain:

- what the figure shows
- the main scientific point
- important simplifications
- relevant evidence boundaries
- provenance and licensing where applicable

Captions should not simply repeat the figure title.

For quantitative figures, cite the underlying data or literature.

For conceptual figures, cite the science supporting the concept where needed.

For photographs, credit the photographer and licence where applicable.

# 12. Production formats

Use:

- SVG for plots and vector diagrams
- high-resolution PNG/TIFF for raster illustrations and photographs
- hybrid image-generated base plus vector/text overlay when useful

Image generation is appropriate for:

- scientific natural-history illustration
- cells
- habitats
- environmental scenes

Programmatic/vector production is preferred for:

- plots
- axes
- quantitative diagrams
- simple schematics

Use the simplest production method that gives a scientifically accurate and publication-quality result.

Where useful, retain an editable source.

# 13. Final figure assets

Publication figures belong in:

`book/figures/`

Final assets should use stable names such as:

`fig18_01_cardinal_temperatures.svg`

`fig18_02_cellular_adaptations.png`

Editable sources may be retained with clearly distinct names such as:

`fig18_02_cellular_adaptations_source.svg`

A figure is complete only when:

- the scientific concept is settled
- one final asset is selected
- the final filename is assigned
- the chapter references it
- caption is complete
- alt text is complete
- prose callout is present
- provenance/licensing are recorded
- the rendered figure has been inspected

Generating candidates alone does not complete a figure.

Do not leave ambiguous competing publication versions in `book/figures/`.

# 14. Scientific accuracy

Aesthetics never override scientific accuracy.

Before accepting a figure, verify as relevant:

- terminology
- organism names
- taxonomy
- units
- ranges
- environmental conditions
- molecular structures
- process direction
- causal interpretation

Do not introduce unsupported biology because it makes the figure visually cleaner or more attractive.

# 15. Final test

Before accepting a figure, ask:

1. What scientific question does it answer?
2. Is the answer visually clear?
3. Does every major element contribute?
4. Is anything present only for decoration?
5. Is it scientifically defensible?
6. Is it legible at final size?
7. Does it work without relying only on colour?
8. Does it look consistent with the rest of the book?

If not, revise it.
